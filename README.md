 🏧 ATM Machine - Python

A clean, interactive command-line ATM simulation built with Python.

This project was built as part of my Python learning journey to practice loops, conditionals, and functions.

✨ Features
- Check Balance
- Deposit Amount
- Withdraw Amount (with insufficient balance check)
- User-friendly Menu System
- Input Validation

🚀 How to Run
1. Clone this repository
2. Run the command: python atm-program.py

🛠️ Tech Stack
- Python 3
